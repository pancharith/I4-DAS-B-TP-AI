TP01 — Introduction to PyTorch

Overview

TP1 introduces the fundamental operations of PyTorch tensors and their applications in machine learning.

Topics Covered

* Tensor creation and matrix multiplication
* Random seeds and reproducibility
* CPU and GPU device management
* Maximum, minimum, and index operations
* Tensor dimension manipulation using squeeze() and permute()
* NumPy interoperability and data types
* Image tensor transformation and flattening
* Feature standardization

Tools and Libraries

* Python
* PyTorch
* NumPy
* Jupyter Notebook

Submission

The completed practical work is provided in the Jupyter Notebook associated with this assignment.
